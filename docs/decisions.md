# 결정 사항 기록

인계문과 포스터가 다르거나 인계문에 없던 부분에서 담임이 정한 내용.

| 항목 | 결정 |
|---|---|
| 랭킹 동점 | 공동 순위 (1, 2, 2, 4) |
| 담임 화면 | 같은 웹앱 주소 + `?page=admin`, 담임 코드로 입장 |
| 설치 방식 | `dist/Code.gs` 한 파일 복사-붙여넣기 |
| 기간·호칭 | 인계문 기준(10/12~10/22, 투투, 중간 업데이트 10/16). 설정 시트에서 변경 가능 |
| 졸지 않기 | 2회 이상 졸면 실패 (인계문 기준) |
| 검거 시 이전 | 암행어사가 **암행어사 활동 보상(+3)** 으로 모은 도장 전부를 지목한 투투에게 이전 |
| 뽑기 보상 | 인계문대로: 일퀘 올클 1회 + 순합계 12개 이상 1회 (둘 다면 2회) |

## 교과 선생님 화면 (4단계)

- 교실 태블릿에서 담임이 교과 링크를 열고 **공통 코드를 한 번** 입력 → 기기에 기억
- 매 수업: **선생님 이름 버튼 선택**(설정 시트 "교과 선생님 목록", `이름(과목)` 형식) → **교시 선택** → 확인 → 학생 이름 → [적극 참여 +2] / [MVP +3]
- **과목은 선택한 선생님에 맞춰 자동 기록**
- 매 수업 코드 재입력 **없음** (교실 태블릿은 학생이 만지지 않는다고 봄)
- 기록장 입력자 = 선생님 이름, 교시·과목 기록. 되돌리기, MVP 교시당 1명, "수업 끝" 버튼, 일정 시간 미사용 시 첫 화면 복귀
