# 결정 사항 기록

인계문과 포스터가 다르거나 인계문에 없던 부분에서 담임이 정한 내용.

| 항목 | 결정 |
|---|---|
| 랭킹 동점 | 공동 순위 (1, 2, 2, 4) |
| 담임 화면 | 같은 웹앱 주소 + `?page=admin`, 담임 코드로 입장 |
| 설치 방식 | `dist/Code.gs` 한 파일 복사-붙여넣기 |
| 기간·호칭 | 인계문 기준(10/12~10/22, 투투, 중간 업데이트 10/16). 설정 시트에서 변경 가능 |
| 졸지 않기 | 교시별 😊/😴 체크, **😴 3개 이하면 성공** (설정 "졸음 허용 횟수"), 하교 후 체크 가능 |
| 인사 2회 | 인사한 선생님 이름 기록, **서로 다른 선생님 2분** |
| 체크 취소 | 도장 받기 전까지 변경 가능, 받은 뒤 변경 불가 |
| 금지어 | 띄어쓰기·기호 섞은 우회도 차단 |
| 칭찬 수정 | 제출 후 수정 불가 |
| 칭찬 내용 | 비난·비판·놀림, 구체적이지 않은 칭찬은 숨김·미션 취소 안내 (담임이 모든 칭찬 확인) |
| 칭찬 숨김 | 받은 칭찬함에 "담임 선생님이 숨긴 칭찬" 표시, 보낸 투투 칭찬 미션 미완료 + 일퀘 도장 자동 취소, 같은 날이면 다시 칭찬 가능, 해제 시 복구 |
| 시간표 | 시간표 시트(요일×교시, 시작시각) + 시간표변경 시트(날짜별 하루 대체). 투투 화면에 오늘의 시간표 |
| 검거 시 이전 | 암행어사가 **암행어사 활동 보상(+3)** 으로 모은 도장 전부를 지목한 투투에게 이전 |
| 모둠 | 사용 안 함 (학생 시트에서 제외) |
| 단체 도장 | 모둠별이 아니라 **반 전체 +3** (담임 대시보드에서 입력) |
| 랭킹 공개 | **매일 실시간 공개**. 숨김은 담임의 랭킹 잠금 스위치로만 (중간 업데이트일은 안내용) |
| 랭킹 잠금 시 | 상위 랭킹과 **내 순위도 숨김** |
| 상위 N 동점 | 공동 순위로 N위 안이면 **모두 공개** (도장 0개는 공개 안 함) |
| 투투 로그인 | 한 번 로그인하면 **캠페인 기간 내내 유지**, 코드 재발급 시 로그아웃 |
| 도장판 | 행성 1개 = 23칸(종이 도장판), 다 채우면 **다음 행성이 열림** (70개 이상 대비) |
| 뽑기 보상 | 인계문대로: 일퀘 올클 1회 + 순합계 12개 이상 1회 (둘 다면 2회) |

## 교과 선생님 화면 (4단계)

- 교실 태블릿에서 담임이 교과 링크를 열고 **공통 코드를 한 번** 입력 → 기기에 기억
- 매 수업: **선생님 이름 버튼 선택**(설정 시트 "교과 선생님 목록", `이름(과목)` 형식) → **교시 선택** → 확인 → 학생 이름 → [적극 참여 +2] / [MVP +3]
- **과목은 선택한 선생님에 맞춰 자동 기록**
- 교시는 **현재 시각으로 자동 선택**(교시 시작 10분 전 ~ 다음 교시 시작 10분 전), 선생님이 바꿀 수 있음
- 매 수업 코드 재입력 **없음** (교실 태블릿은 학생이 만지지 않는다고 봄)
- 기록장 입력자 = 선생님 이름, 교시·과목 기록. 되돌리기, MVP 교시당 1명, "수업 끝" 버튼, 일정 시간 미사용 시 첫 화면 복귀
