# 바른 언어 사용하고, 보상 얻자!! — 학급 캠페인 웹앱

Google 스프레드시트 + Apps Script로 만드는 2주 바른 언어 캠페인 웹앱입니다.
모든 도장은 **기록장** 시트에 한 줄씩 쌓이고, 합계·랭킹은 기록장에서 자동 계산됩니다.

## 진행 상황

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 시트 구조 + 설정 + 기록장 합계/랭킹 + 담임 대시보드 기본 | ✅ 작성 |
| 2 | 투투 로그인 + 랭킹/내 도장판 + 30초 갱신 | ✅ 작성 |
| 3 | 일일퀘스트 + 온라인 칭찬 + 시간표 | ✅ 작성 |
| 4 | 교과 선생님 태블릿 화면 + 단체 도장 | ✅ 작성 |
| 5 | 암행어사 판정 + 지목/검거 이전 | ⏳ |
| 6 | 쿠폰 뽑기 대상 + 마무리 디자인 | ⏳ |

## 화면 주소 (배포 후)

| 화면 | 주소 | 입장 방법 |
|---|---|---|
| 투투 화면 | `웹앱주소` | 번호 + 로그인 코드 |
| 교과 선생님 | `웹앱주소?page=teacher` | 교과 선생님 공통 코드 (태블릿에서 처음 한 번) |
| 담임 대시보드 | `웹앱주소?page=admin` | 담임 코드 |

주소는 하나이고, 끝에 `?page=admin`을 붙이면 담임 화면이 열립니다.
주소를 알아도 **담임 코드가 없으면 들어갈 수 없고**, 모든 확인은 서버에서 합니다.

## 설치·배포 방법 (복사-붙여넣기, 처음 한 번)

> "배포"는 스프레드시트에 붙은 스크립트를 **인터넷 주소(웹앱)로 공개**하는 작업입니다.
> 배포하면 `https://script.google.com/macros/s/.../exec` 모양의 주소가 생기고,
> 투투들은 이 주소로 접속합니다. 스프레드시트 파일 자체는 담임만 열 수 있습니다.

### 1. 스프레드시트와 스크립트 만들기
1. Google 드라이브 → **새로 만들기 → Google 스프레드시트** (이름 예: `바른언어 캠페인`)
2. 상단 메뉴 **확장 프로그램 → Apps Script** 클릭 → 스크립트 편집기가 열림

### 2. 코드 붙여 넣기 (파일 1개)
1. 아래 주소를 열면 코드 전체가 글자로 보입니다.
   https://raw.githubusercontent.com/bon17/class-language-campaign/claude/laughing-darwin-4vu9nz/dist/Code.gs
2. **Ctrl+A**(전체 선택) → **Ctrl+C**(복사)
3. Apps Script 편집기의 `Code.gs` 안에 있던 내용을 **모두 지우고** → **Ctrl+V**(붙여넣기)
4. 💾 **저장** (Ctrl+S)

> 휴대폰보다 **컴퓨터**에서 하는 것을 권장합니다 (Apps Script 편집기가 모바일에서 불편합니다).
> 다른 파일(HTML, appsscript.json)은 만들 필요 없습니다. 이 한 파일에 화면까지 모두 들어 있습니다.

### 3. 시트 초기 세팅
1. 스프레드시트 탭으로 돌아가 **새로고침** → 상단에 **🚀 캠페인** 메뉴가 생김
2. **🚀 캠페인 → 시트 초기 세팅** 실행 (처음엔 권한 허용 창이 뜸: 내 계정 선택 → 고급 → 이동 → 허용)
3. 완료 창에 **담임 코드**와 **교과 선생님 코드**가 표시됩니다 (설정 시트에서도 확인 가능)
4. **학생** 시트의 예시 3줄을 지우고 반 명단(번호·이름)을 붙여 넣기
5. **🚀 캠페인 → 빈 로그인 코드 채우기** → 학생별 4자리 코드 자동 생성

### 4. 웹앱으로 배포
1. Apps Script 편집기 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴 ⚙️ → **웹 앱** 선택
3. **다음 사용자 인증 정보로 실행: 나**, **액세스 권한이 있는 사용자: 모든 사용자**
4. **배포** → 나오는 **웹 앱 URL**을 복사 (스프레드시트의 **🚀 캠페인 → 웹앱 주소 보기**로도 확인)

### 새 단계 코드로 업데이트하려면
위 주소에서 최신 `Code.gs`를 다시 복사해 편집기 내용을 통째로 바꿔 붙여 넣고 저장 → **배포 → 배포 관리 → ✏️(수정) → 버전: 새 버전 → 배포**.
이렇게 하면 **주소가 바뀌지 않고** 새 코드가 반영됩니다. ("새 배포"를 누르면 주소가 새로 생기니 주의)

> 개발자용: 원본은 `src/` 폴더에 나뉘어 있고, `node tools/bundle.js`로 `dist/Code.gs` 한 파일을 만듭니다.
> [clasp](https://github.com/google/clasp)을 쓰면 `src/`를 그대로 올려도 됩니다
> (`.clasp.json`에 `{"scriptId": "<스크립트 ID>", "rootDir": "src"}` 작성 후 `clasp push`).

## 시트 구조

| 시트 | 열 | 비고 |
|---|---|---|
| 설정 | 항목, 값, 설명 | 담임은 **값** 칸만 수정. ON/OFF, 날짜는 `2026-10-12` 형식 |
| 학생 | 번호, 이름, 로그인코드 | 코드는 메뉴로 발급·재발급 |
| 기록장 | 타임스탬프, 날짜, 학생번호, 미션구분, 점수, 입력자유형, 입력자, 교시, 과목, 메모, 취소여부, 기록ID, 취소사유 | **유일한 원본**. 행을 지우지 말고 취소 처리 |
| 일퀘 | 날짜, 학생번호, 칭찬완료, 인사완료, 졸지않기완료, 도장지급여부, 인사선생님1·2, 교시별졸음, 수정시각 | 자동 기록 |
| 칭찬 | 타임스탬프, 날짜, 보낸번호, 받은번호, 내용, 숨김여부, 고마워여부, 칭찬ID | 숨김은 담임 대시보드에서 |
| 암행어사 | 주차, 학생번호, 시작일, 종료일, 상태 | 5단계 |
| 암행어사판정 | 날짜, 암행어사번호, 바른1·2·3위, 나쁜1·2·3위 | 5단계 |
| 지목 | 타임스탬프, 지목한번호, 지목된번호, 결과 | 5단계 |
| 뽑기 | 학생번호, 일퀘올클여부, 도장12개여부, 뽑기횟수, 뽑기완료횟수 | 6단계 |
| 시간표 | 교시, 시작시간, 월~금 | 빈 칸 = 수업 없음. 처음엔 2-2 2학기 시간표가 들어 있음 |
| 시간표변경 | 날짜, 1~7교시, 메모 | 행사 등으로 바뀌는 날만 한 줄. 그날은 이 줄이 하루 전체를 대신함 |

> 코드를 새로 붙여 넣으면 웹앱이 처음 열릴 때 새 시트·새 열이 자동으로 추가됩니다 (시트 초기 세팅을 다시 안 해도 됨).

- 미션구분: `일퀘 / 암행어사판정 / 암행어사활동 / 수업참여 / MVP / 단체 / 검거이전 / 수동`
- 입력자유형: `학생 / 암행어사 / 교과 / 담임 / 시스템`
- 기록장에는 인계문 열 외에 **기록ID**(취소·되돌리기용)와 **취소사유** 열을 추가했습니다.

결정 사항은 [docs/decisions.md](docs/decisions.md)에 정리되어 있습니다.

## 설정 항목

캠페인명, 부제, 학생 호칭(기본 "투투"), 시작일, 종료일, 등교일 목록, 중간 랭킹 업데이트일,
랭킹 공개 인원, 랭킹 잠금, 뽑기 도장 기준, 칭찬 최소 글자 수, 금지어 목록, 교과 선생님 목록(`이름(과목)`), 교과 선생님 공통 코드,
담임 코드, 지목 결과 공개, 교시 수, 1~5위 보상.

시트를 직접 고치면 자동으로 캐시가 비워져 바로 반영됩니다. 반영이 안 보이면
**🚀 캠페인 → 캐시 비우기** 또는 대시보드 설정 탭의 **시트 다시 읽기**를 누르세요.

## 계산 규칙

- **총점** = 기록장에서 취소되지 않은 모든 점수(+/−)의 합
- **순위**: 총점 내림차순, 동점은 **공동 순위** (예: 1, 2, 2, 4)
- 합계·랭킹은 서버에서 계산 후 5분 캐시, 기록장에 쓰기가 생기면 즉시 무효화
- 모든 쓰기는 LockService로 보호

## 담임 대시보드 (1단계 기능)

- 📊 현황: 오늘 몇 일차, 투투별 미션별 합계·차감·총점·순위, 데이터 경고(번호 중복, 코드 누락 등)
- ✍️ 도장 입력: 여러 명/반 전체 선택 → 수동 도장 추가·차감 (사유 필수)
- 📜 기록장: 투투·미션별 필터, 기록 취소 (사유 필수, 행은 남고 취소 표시)
- ⚙️ 설정: 랭킹 잠금 스위치, 현재 설정·보상 확인, 스프레드시트 바로가기

## 투투 화면 (2단계)

- 번호 + 4자리 코드 로그인 → 캠페인 종료 2주 뒤까지 유지 (코드 재발급 시 자동 로그아웃, 번호별 10분 5회 실패 시 잠시 차단)
- 🏆 랭킹: 도장 1개 이상인 투투 중 상위 N위(공동 순위면 모두) 공개, 내 순위는 본인만, 직전 등교일 대비 ▲▼. 랭킹 잠금 ON이면 "랭킹 공개 전입니다"(내 순위도 숨김)
- 🌍 도장판: 종이 도장판처럼 행성 1개 = 23칸. 다 채우면 다음 행성(색이 바뀜)이 열리고 번호가 이어짐
- 📊 미션별 도장(일퀘/암행어사 판정/수업/단체/기타), 🔥 일퀘 연속, 🎟 뽑기권, 12개까지 남은 도장
- ✅ 일퀘판: 등교일별 O/X + 칭찬한 친구 이름 (3단계에서 채워짐)
- ✍️ 싸인판: 수업 적극 참여/MVP 도장이 과목·교시와 함께 칸에 채워짐
- 📜 내 도장 기록·차감 내역 (누가 줬는지는 표시하지 않음)
- 30초마다 자동 갱신 + 새로고침 버튼

## 일일퀘스트·칭찬 (3단계)

- 오늘 날짜 + 등교일만 입력 가능 (서버 시각 기준), 3가지를 모두 완료하면 **도장 +1 자동 지급**, 지급 뒤에는 체크 변경 불가
- 💌 칭찬: 친구 선택 + 문장 작성, 하루 1회, 기간 중 같은 친구 다시 불가, 자기 자신 불가, 최소 글자 수, 금지어(띄어쓰기·기호로 우회해도 걸러냄) → "바른 언어로 다시 써볼까요?"
- 🙇 인사 2회: 인사한 **서로 다른 선생님 2분**을 기록 (설정의 교과 선생님 목록 버튼 또는 직접 입력)
- 😴 졸지 않기: 오늘 시간표의 교시마다 😊/😴 선택, 😴가 **졸음 허용 횟수(기본 3) 이하**면 성공
- 📬 받은 칭찬함: 보낸 친구 이름 + 내용, 💗고마워 버튼. 다른 투투는 볼 수 없음
- 칭찬 입력란에 "담임 선생님이 모든 칭찬을 확인, 비난·비판·놀림이나 구체적이지 않은 칭찬은 숨김·미션 취소" 안내
- 담임이 칭찬을 **숨기면**: 받은 칭찬함에 "담임 선생님이 숨긴 칭찬"으로 표시, 보낸 투투에게 숨김 안내, 그날 칭찬 미션 미완료 + 일퀘 도장 자동 취소(오늘이면 다시 칭찬 가능). **해제하면** 원래대로 복구
- 담임: ✅ 일퀘 탭(날짜×투투 달성표), 💌 칭찬 탭(필터·숨김·한 번도 못 받은 투투)

## 교과 선생님 화면 (4단계)

- 교실 태블릿에서 `?page=teacher` 열고 **공통 코드 한 번** 입력 → 기간 동안 유지 (설정에서 코드를 바꾸면 다시 잠김)
- 선생님 이름 버튼(설정 "교과 선생님 목록") → 교시(**현재 시각으로 자동 선택**, 변경 가능) → 확인
- 투투 이름 → [➕ 적극 참여 +2] / [🏅 MVP +3]
  - +2는 같은 교시에 한 투투 1번, MVP는 같은 교시에 1명 (둘 다 받는 것은 가능)
  - ✓ 오늘 수업 도장 받음, 노란 테두리 = 최근 3등교일 수업 도장이 가장 적은 투투
  - 입력 직후 8초간 되돌리기 바 + "이번 교시 기록"에서 언제든 되돌리기 (기록장 취소 처리)
- [수업 끝] 또는 5분 동안 입력이 없으면 첫 화면으로
- 기록장: 입력자유형 "교과", 입력자 = 선생님 이름, 교시·과목 기록
- 담임 대시보드 ✍️ 도장 입력 탭: **🤝 반 전체 단체 도장 +3** (횟수 제한 없음)

## 보안 메모

- 웹앱은 "나로서 실행"이라 투투는 스프레드시트에 직접 접근할 수 없고, 서버 함수가 돌려주는 것만 봅니다.
- 담임 기능은 담임 코드 로그인 후 받은 토큰(6시간)이 있어야 호출됩니다. 10분에 10회 이상 틀리면 잠시 차단됩니다.
- 로그인 코드·기록장 입력자는 담임 대시보드 외에는 내려보내지 않습니다.
